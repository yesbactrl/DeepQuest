# Живой тест DeepQuest

## 1. Бот в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя (его видно в чате): `DeepQuest`.
3. Username: должен заканчиваться на `bot`, например `deepquest_myname_bot`. `DeepQuestBot`, скорее всего, занят.
4. BotFather пришлёт токен вида `123456789:AA…`. Это пароль от бота: не показывай его никому и не присылай в чат.
5. По желанию: `/setuserpic` и `/setdescription`. Меню команд бот выставит сам при запуске.

## 2. Ключ Claude API

1. [console.anthropic.com](https://console.anthropic.com) → Settings → API Keys → Create Key.
2. Billing: пополни баланс, иначе запросы вернут ошибку.
3. Ориентир по расходам — $5–10 в месяц: задачи оформляет Haiku (доли цента), отчёты проверяет Opus (около $0.05 за проверку).

## 3. Настройки

```bash
cp .env.example .env
```

```bash
open -e .env
```

Впиши `BOT_TOKEN` и `ANTHROPIC_API_KEY`, `ALLOWED_TELEGRAM_IDS` пока оставь пустым. `.env` лежит в `.gitignore` и в git не попадёт.

Проверь агента без Telegram: должен прийти JSON с задачей про TikTok, целью `id=2` («Арбитраж трафика») и множителем около ×1.5.

```bash
uv run python -m deepquest.agent "надо бы глянуть, как люди льют на тиктоке, и запустить кампанию баксов на двадцать"
```

## 4. Запуск

```bash
uv run deepquest
```

Напиши боту что угодно: он ответит твоим telegram_id. Впиши его в `.env` как `ALLOWED_TELEGRAM_IDS=…`, останови бота (Ctrl+C) и запусти снова.

## 5. Что проверить

- [ ] `/start`: пояс (кнопка «Как на этом Mac»), норма, время утра и вечера.
- [ ] Сразу после онбординга бот просит первую цель; «зачем»; «➕ Направление» и «Пропустить».
- [ ] `/goals`: список, карточка, переименование, «зачем».
- [ ] Перезапуск посреди сценария: начни добавлять цель, останови бота, запусти снова и допиши — сценарий продолжается.
- [ ] Мысль текстом → карточка с целью, оценкой и множителем. Две мысли в одном сообщении → две карточки.
- [ ] Размытая мысль («поизучать тикток») → уточняющий вопрос → ответ → карточка.
- [ ] «Поправить»: «не 2 часа, а 4» или «это к цели …» → новая карточка.
- [ ] «Сохранить» → «▶️ Старт» → подожди пару минут → «✅ Готово».
- [ ] Отчёт со скрином → вердикт и XP → «❓ Почему столько?».
- [ ] Отчёт без пруфа → в расчёте ×0.8.
- [ ] «⚖️ Оспорить» → аргумент → пересмотр; второй раз оспорить нельзя.
- [ ] `/go`, `/pause`, `/done`; запуск второй задачи ставит первую на паузу.
- [ ] `/backlog`: открыть задачу, убрать её.

## Если что-то не так

- Логи — в терминале, где запущен бот.
- Последние вызовы агента (модель, токены, задержка, ошибка):

  ```bash
  sqlite3 ~/Library/Application\ Support/DeepQuest/deepquest.db "select id, kind, model, stop_reason, tokens_in, tokens_out, latency_ms, error from agent_calls order by id desc limit 10"
  ```

- Пока Mac спит, бот молчит: сообщения обработаются после пробуждения.
- Всё, что показалось странным в оценках, вердиктах или текстах, записывай — по этим примерам поправим промпты.
