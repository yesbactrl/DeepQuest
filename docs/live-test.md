# Живой тест DeepQuest

## 1. Бот в Telegram

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Имя (его видно в чате): `DeepQuest`.
3. Username: должен заканчиваться на `bot`, например `deepquest_myname_bot`. `DeepQuestBot`, скорее всего, занят.
4. BotFather пришлёт токен вида `123456789:AA…`. Это пароль от бота: не показывай его никому и не присылай в чат.
5. По желанию: `/setuserpic` и `/setdescription`. Меню команд бот выставит сам при запуске.

## 2. Claude: через подписку

Агент работает через Claude Code по твоей подписке, ключ API не нужен. Проверь, что ты вошёл:

```bash
claude auth status --text
```

Должно быть написано, что вход выполнен через claude.ai. Если нет — выполни `claude auth login`.

Ключ Claude API нужен, только если захочешь платный бэкенд (`AGENT_BACKEND=api`) или запасной вариант на случай, когда кончатся лимиты подписки (`AGENT_API_FALLBACK=true`). Тогда создай ключ на [console.anthropic.com](https://console.anthropic.com) → Settings → API Keys и пополни баланс.

## 3. Настройки

```bash
cp .env.example .env
```

```bash
open -e .env
```

Впиши `BOT_TOKEN`, `ALLOWED_TELEGRAM_IDS` пока оставь пустым. `.env` лежит в `.gitignore` и в git не попадёт.

Проверь агента без Telegram: должен прийти JSON с задачами про TikTok и целью `id=2` («Арбитраж трафика»).

```bash
uv run python -m deepquest.agent "надо бы глянуть, как люди льют на тиктоке, и запустить кампанию баксов на двадцать"
```

## 4. Запуск

```bash
uv run deepquest
```

Напиши боту что угодно: он ответит твоим telegram_id. Впиши его в `.env` как `ALLOWED_TELEGRAM_IDS=…`, останови бота (Ctrl+C) и запусти снова.

## 5. Что проверить

- [ ] `/start`: пояс (кнопка «Как на этом Mac»), норма, время утра и вечера.
- [ ] Сразу после онбординга бот просит первую цель; «зачем»; «➕ Направление» и «Пропустить».
- [ ] `/goals`: список, карточка, переименование, «зачем».
- [ ] Перезапуск посреди сценария: начни добавлять цель, останови бота, запусти снова и допиши — сценарий продолжается.
- [ ] Мысль текстом → карточка с целью, оценкой и множителем. Две мысли в одном сообщении → две карточки.
- [ ] Размытая мысль («поизучать тикток») → уточняющий вопрос → ответ → карточка.
- [ ] «Поправить»: «не 2 часа, а 4» или «это к цели …» → новая карточка.
- [ ] «Сохранить» → «▶️ Старт» → подожди пару минут → «✅ Готово».
- [ ] Отчёт со скрином → вердикт и XP → «❓ Почему столько?».
- [ ] Отчёт без пруфа → в расчёте ×1, со скрином или ссылкой → ×1.1.
- [ ] План: перетащи задачу из «Когда-нибудь» на завтра; в карточке задачи «Когда» показывает этот день; `/today` в боте — план на сегодня.
- [ ] Дневник: `/d проснулся разбитый` → ответ с оценками и факторами; `/d` → голосовое → запись. В вебе запись появляется в ленте, оценки правятся.
- [ ] «Засчитать без проверки» → задача закрыта без агента, XP по той же формуле, оспорить нельзя.
- [ ] «⚖️ Оспорить» → аргумент → пересмотр; второй раз оспорить нельзя.
- [ ] `/go`, `/pause`, `/done`; запуск второй задачи ставит первую на паузу.
- [ ] `/backlog`: открыть задачу, убрать её.
- [ ] «Персонаж»: задача по направлению → уведомление «+N XP общий · +N Цель · +N Направление», уровни стата и скилла растут; у отстающей цели плашка «Самый слабый стат».
- [ ] Цель → «Изменить»: цвет, иконка, «XP только за рост». Мысль «отработал смену» по такой цели → агент спрашивает про шаг роста.
- [ ] Голосовое с мыслью → «🎙 …» с расшифровкой → карточка. Голосом же ответить на уточнение и сдать отчёт.
- [ ] Веб: 🎙 у поля «Что хочешь сделать?» → разрешить микрофон → сказать фразу → ■ → текст в поле.
- [ ] Служба: остановить бота в терминале, `uv run deepquest service install` → через полминуты `service status` показывает `state = running`, веб открывается, бот отвечает. `uv run deepquest` в терминале теперь сразу выходит с подсказкой про `service restart`.
- [ ] «Итоги»: неделя и месяц, стрелки назад; цифры сходятся с дашбордом; «Разобрать» → через минуту ретроспектива, после обновления страницы она на месте.
- [ ] «Сон»: «Записать сон» подставляет привычные отбой и подъём; клик по пустому месту строки — дневной сон с этого времени; пересечение с другим сном не сохраняется; норма меняется, график и плитки пересчитываются; сон виден в «Итогах».
- [ ] ⌘K → «Поиск»: слово из отчёта находит задачу с куском текста, слово из дневника — запись; регистр и «ё» не мешают.
- [ ] Советник: в Claude Desktop в новом чате «что у меня сегодня?» → вызывается `overview`, ответ с задачами и сном; «заведи задачу …» → задача в бэклоге с меткой `[советник]`.
- [ ] Бэкап: в `~/Library/Application Support/DeepQuest/backups/` есть `deepquest-<сегодня>.db`.

## Если что-то не так

- Логи — в терминале, где запущен бот, а у службы — `uv run deepquest service logs`.
- Каждый ответ агента занимает 5–10 секунд: так работает запуск Claude Code.
- Последние вызовы агента (модель, токены, задержка, ошибка):

  ```bash
  sqlite3 ~/Library/Application\ Support/DeepQuest/deepquest.db "select id, kind, model, stop_reason, tokens_in, tokens_out, latency_ms, error from agent_calls order by id desc limit 10"
  ```

- Пока Mac спит, бот молчит: сообщения обработаются после пробуждения.
- Всё, что показалось странным в оценках, вердиктах или текстах, записывай — по этим примерам поправим промпты.
