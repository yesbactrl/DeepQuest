# DeepQuest

Telegram-бот для личной прокачки: цели, задачи, таймер, отчёты, которые проверяет Claude, и XP за реальные шаги.

- Что строим: [docs/product-spec.md](docs/product-spec.md)
- Как устроено: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Как создать бота и проверить всё вживую: [docs/live-test.md](docs/live-test.md)

## Запуск

Нужен [uv](https://docs.astral.sh/uv/).

1. Создай бота в [@BotFather](https://t.me/BotFather) и получи токен.
2. Агент по умолчанию работает через Claude Code по твоей подписке: нужен установленный `claude`, в который ты вошёл (`claude auth status`). Скопируй настройки и впиши токен в `BOT_TOKEN`. Ключ Claude API (`ANTHROPIC_API_KEY`) нужен только для `AGENT_BACKEND=api` или как запасной вариант:

   ```bash
   cp .env.example .env
   ```

3. Запусти бота:

   ```bash
   uv run deepquest
   ```

4. Напиши боту что угодно. Пока `ALLOWED_TELEGRAM_IDS` пуст, он ответит твоим telegram_id. Впиши id в `.env`, перезапусти бота и отправь `/start`.

База лежит в `~/Library/Application Support/DeepQuest/deepquest.db`, миграции применяются сами при старте. Раз в день рядом, в `backups/`, появляется копия базы; хранятся последние 14.

Чтобы DeepQuest работал без открытого терминала, стартовал при входе в систему и поднимался сам после падения, поставь его службой macOS:

```bash
uv run deepquest service install
```

После обновления кода — `uv run deepquest service restart`. Посмотреть, жив ли, — `service status`, журнал — `service logs`, убрать службу — `service uninstall`.

После онбординга любое сообщение боту — это новая задача: агент оформит карточку, а ты сохранишь её в бэклог (`/backlog`), поправишь или отменишь. Цели — `/goals`.

Задачи и отчёты можно надиктовать голосовым: бот покажет, что расслышал, и продолжит как с текстом. Распознаёт локальный Whisper прямо на Маке. Модель (~1,5 ГБ) скачается сама при первом запуске, выключить голос — `VOICE_ENABLED=false`.

Бот можно поставить на паузу и пользоваться только вебом: `BOT_ENABLED=false` в `.env`, токен тогда не нужен.

Работа над задачей: «▶️ Старт» на карточке (или `/go`) запускает таймер, «⏸ Пауза» (`/pause`) останавливает, «✅ Готово» (`/done`) просит отчёт. Агента можно не звать: «Засчитать без проверки» закрывает задачу сразу. Пруф необязателен: без него ×1, со скрином или ссылкой — ×1.1 за данные для истории. Таймер не обязателен: без него время засчитывается по оценке, а в вебе можно вписать, сколько ушло на самом деле, и поправить время у закрытой задачи. Отчёт — текст и пруф (скрин или ссылка); агент выносит вердикт, бот начисляет XP и по кнопке объясняет расчёт. Вердикт можно один раз оспорить.

## Веб

Веб — основной интерфейс, бот — для быстрого ввода. Оба работают в одном процессе `uv run deepquest`, веб открывается на <http://127.0.0.1:8484> и только с этого Mac.

В вебе есть цели и задачи: мысль через агента, бэклог с фильтрами, ручная правка карточки, таймер (виден в шапке), отчёт со скриншотами (можно вставить через ⌘+V), вердикт, расчёт XP и оспаривание. У полей задачи есть кнопка микрофона: расшифровка дописывается в поле, и её можно поправить перед отправкой. «План»: задачи раскидываются по дням недели перетаскиванием, над днём видно, сколько набрано против нормы; в боте — `/today`. «Дневник» (+15 XP за каждую запись): пара фраз о том, как ты, — агент оценит настроение, энергию и желание действовать, выделит, что повлияло, и разложит запись по целям («Капитал: огорчает аренда», «Медийка: радует канал»); лента фильтруется по цели; в боте — `/d`. «Сон»: ночной и дневной сон по дням — отрезками на шкале, норма, средние отбой и подъём, недосып и как сон связан с состоянием и фокусом. «Итоги»: неделя или месяц — XP, фокус, задачи и норма против того же отрезка прошлого периода, состояние по дням, каждая сфера с оценкой из дневника и заметками, плохие и хорошие дни и что их сопровождало; по кнопке агент пишет ретроспективу и 1–3 фокуса дальше. Поиск по задачам с отчётами и по дневнику — ⌘K с любой страницы. «Персонаж»: цели — это статы, направления — скиллы, у каждого свой уровень; задача качает сразу общий уровень, стат и скилл, а самый отстающий стат получает +20% XP. Цвет, иконка и «XP только за рост» — в настройках цели. Дашборд: уровень, сезон, норма на сегодня, стрик (норму и стрик можно поставить на паузу) и настраиваемые графики (метрика, период, разбивка, вид, табличный вид). В боте то же — `/stats`.

Фронтенд нужно собрать один раз и после каждого изменения в `web/` (перезапускать бота не нужно):

```bash
cd web && npm install && npm run build
```

Для разработки фронтенда с горячей перезагрузкой — dev-сервер Vite на <http://127.0.0.1:5173>, запросы к `/api` он передаёт запущенному боту:

```bash
cd web && npm run dev
```

## Советник

С данными DeepQuest можно просто разговаривать: про задачи, план, сон, самочувствие. Проще всего — на странице «Советник» в вебе: каждый разговор — свой контекст, ответ пишется на глазах и не теряется, если уйти со страницы, есть микрофон и выбор модели (Sonnet быстрее, Opus глубже). Советник сам запоминает устойчивое о тебе — «что он помнит» видно и правится по кнопке 🧠. Работает через Claude Code по подписке.

Тот же советник доступен из Claude Desktop и Claude Code. Это MCP-сервер `uv run deepquest mcp` — Claude Desktop или Claude Code запускают его сами и через него читают задачи, цели, план, дневник, сон, итоги и поиск, а по просьбе заводят задачу, ставят её на день, пишут в дневник или записывают сон. Удалять и начислять XP советник не может. Каждый чат в клиенте — отдельный разговор со своим контекстом.

Claude Desktop — в `~/Library/Application Support/Claude/claude_desktop_config.json`, затем перезапустить приложение:

```json
"mcpServers": {
  "deepquest": {
    "command": "/opt/homebrew/bin/uv",
    "args": ["run", "--directory", "/Users/<ты>/DeepQuest", "deepquest", "mcp"],
    "env": { "PATH": "/opt/homebrew/bin:/Users/<ты>/.local/bin:/usr/bin:/bin" }
  }
}
```

Claude Code:

```bash
claude mcp add --scope user deepquest -- /opt/homebrew/bin/uv run --directory /Users/<ты>/DeepQuest deepquest mcp
```

## Разработка

```bash
uv run pytest
```

```bash
uv run ruff check . && uv run ruff format --check .
```

```bash
cd web && npm run typecheck
```

Проверить промпт оформления задач на настоящей модели, без Telegram (бэкенд — как у бота; цели демонстрационные):

```bash
uv run python -m deepquest.agent "надо бы глянуть, как люди льют на тиктоке, и запустить кампанию баксов на двадцать"
```

Новая миграция после изменения `db/models.py` (CLI работает с черновой базой в `./data`):

```bash
uv run alembic upgrade head && uv run alembic revision --autogenerate -m "что изменилось"
```
